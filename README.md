# Olist Category Prioritization Analysis

## О проекте

В этом проекте исследуется, совпадают ли категории-лидеры по выручке с категориями, которые выглядят наиболее привлекательными с более широкой бизнес-точки зрения.

Для этого категории сравниваются не только по объему продаж, но и по:
- прокси-оценке коммерческого вклада категории,
- клиентской оценке,
- логистической нагрузке,
- операционной устойчивости.

---

## Гипотеза

Наиболее продаваемые категории не обязательно являются лучшими объектами для приоритизации и дальнейшего продвижения. Более привлекательными для дополнительного маркетингового фокуса могут быть категории, которые сочетают высокую прокси-оценка коммерческого вклада, более высокую удовлетворенность клиентов и более низкий операционный риск.

---

## Цель проекта

Определить категории, которые одновременно сильны по коммерческим результатам и устойчивы с операционной точки зрения, и сравнить их с категориями-лидерами по выручке.

---

## Бизнес-эффект

Данный анализ может помочь более обоснованно приоритизировать товарные категории, учитывая не только объем продаж, но и качество экономики, клиентский опыт и устойчивость исполнения заказов.

---

## Данные

Проект выполнен на основе публичного e-commerce датасета **Olist** с Kaggle.

Ссылка на датасет:  
[Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)


Используемые таблицы:
- `orders`
- `order_items`
- `order_payments`
- `order_reviews`
- `customers`
- `products`
- `product_category_name_translation`

--- 

## Что было сделано

В рамках проекта были выполнены следующие шаги:

1. Объединение исходных таблиц в единый аналитический датасет.
2. Фильтрация доставленных заказов.
3. Построение производных признаков:
   - длительность доставки,
   - доля опозданий,
   - логистическая нагрузка,
   - прокси-оценка коммерческого вклада категории.
4. Агрегация данных на уровне товарных категорий.
5. Сравнение категорий по нескольким бизнес-метрикам.
6. Построение многокритериального score для приоритизации категорий.
7. Сравнение ранжирования по выручке и по итоговому score.

---

## Ключевые выводы

- Категории-лидеры по выручке не полностью совпадают с категориями, которые выглядят наиболее сильными по многокритериальной оценке.
- Одного объема продаж недостаточно для более обоснованной приоритизации категорий.
- Некоторые категории оказываются недооцененными при анализе только по общему доходу, который они приносят, а некоторые — переоцененными.
- Более сбалансированный подход к приоритизации должен учитывать не только продажи, но и прокси-оценку коммерческого вклада, клиентский опыт и устойчивость исполнения заказов.

---

## Основные результаты

В рамках проекта были построены:

- сводная таблица по товарным категориям;
- итоговые группы рекомендаций по категориям;
- сравнение ранжирования категорий по выручке и по многокритериальному score;
- визуализации, показывающие различия между категориями по коммерческим, клиентским и операционным метрикам.
